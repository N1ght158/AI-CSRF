# 目录约定

- `docs/`：项目文档，包括命令说明和目录说明。
- `src/`：核心实现代码。
- `src/csrf_autopilot.py`：命令入口，只负责调用内部 CLI。
- `src/ai_csrf/cli.py`：命令行参数解析与启动流程。
- `src/ai_csrf/config.py`：运行参数对象与配置转换。
- `src/ai_csrf/repository.py`：仓库地址解析、目录布局、分支准备。
- `src/ai_csrf/checks.py`：环境检查（git、token、远端可访问性）。
- `src/ai_csrf/git_client.py`：Git 与外部命令执行封装。
- `src/ai_csrf/plan_builder.py`：执行计划组装。
- `src/ai_csrf/csrf_autopilot_app.py`：主流程编排，串联扫描、修复、CI、PR、合并。
- `src/ai_csrf/rules.py`：CSRF 扫描规则定义。
- `src/ai_csrf/csrf_analyzer.py`：静态扫描与风险识别。
- `src/ai_csrf/ai_client.py`：AI 客户端抽象与 Codex 调用实现（A1）。
- `src/ai_csrf/ai_repair_decision_engine.py`：AI 修复决策引擎（A2）。
- `src/ai_csrf/repair_decision.py`：规则决策引擎（AI 失败时可回退）。
- `src/ai_csrf/backend_fixer.py`：后端修复 MVP 生成。
- `src/ai_csrf/frontend_fixer.py`：前端修复 MVP 生成。
- `src/ai_csrf/ci_gate_validator.py`：CI 闸门检查。
- `src/ai_csrf/pull_request_creator.py`：自动提交与创建 PR。
- `src/ai_csrf/auto_merge_executor.py`：on-green 自动合并策略执行。
- `src/ai_csrf/reports.py`：各阶段 JSON/Markdown 报告输出。
- `scripts/`：PowerShell 脚本入口与本地辅助脚本。
- `reports/`：运行报告产物目录（计划、扫描、决策、修复、CI、PR、合并）。
- `repos/`：运行时拉取的目标仓库目录。
- `progress/`：阶段记录与阶段总览，不放业务代码。
