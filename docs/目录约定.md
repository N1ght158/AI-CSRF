# 目录约定

- `README.md`：项目简介、当前进展和核心演示命令。
- `docs/`：项目说明文档。
- `docs/命令使用.md`：常用命令、环境准备和测试流程。
- `docs/目录约定.md`：项目目录说明。
- `src/`：核心实现代码。
- `src/csrf_autopilot.py`：命令入口，只负责调用内部 CLI。
- `src/ai_csrf/cli.py`：命令行参数解析与启动流程。
- `src/ai_csrf/config.py`：运行参数对象与配置转换。
- `src/ai_csrf/repository.py`：仓库地址解析、目录布局、分支准备。
- `src/ai_csrf/checks.py`：环境检查，包括 git、token 和远端访问能力。
- `src/ai_csrf/git_client.py`：Git 与外部命令执行封装。
- `src/ai_csrf/plan_builder.py`：执行计划组装。
- `src/ai_csrf/csrf_autopilot_app.py`：主流程编排，串联扫描、AI 决策、补丁、CI、PR 和合并。
- `src/ai_csrf/rules.py`：CSRF 扫描规则定义。
- `src/ai_csrf/csrf_analyzer.py`：静态扫描与风险识别。
- `src/ai_csrf/ai_client.py`：AI 客户端抽象与 Codex 调用实现。
- `src/ai_csrf/ai_repair_decision_engine.py`：AI 修复决策引擎。
- `src/ai_csrf/ai_patch_draft_generator.py`：AI 补丁草案生成与已有草案读取。
- `src/ai_csrf/ai_patch_applier.py`：AI 补丁确认落地与路径白名单控制。
- `src/ai_csrf/repair_decision.py`：规则决策引擎，AI 失败时可回退。
- `src/ai_csrf/backend_fixer.py`：后端规则修复 MVP。
- `src/ai_csrf/frontend_fixer.py`：前端规则修复 MVP。
- `src/ai_csrf/ci_gate_validator.py`：CI 闸门检查，支持识别常见子目录项目。
- `src/ai_csrf/pull_request_creator.py`：自动提交、推送分支并创建 PR。
- `src/ai_csrf/auto_merge_executor.py`：on-green 自动合并策略评估与执行。
- `src/ai_csrf/reports.py`：各阶段 JSON/Markdown 报告输出。
- `scripts/`：PowerShell 脚本入口。
- `playground/`：用于演示和测试的最小前后端靶场示例，不属于插件核心代码。
- `reports/`：运行报告产物目录，通常不作为核心代码提交。
- `repos/`：运行时拉取的目标仓库目录，通常不作为核心代码提交。
- `progress/`：阶段记录与阶段总览，不放业务代码。
