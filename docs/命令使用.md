# 命令使用

## 环境准备

首次运行前建议确认以下命令可用：

```powershell
git --version
gh --version
node -v
npm.cmd -v
```

Windows PowerShell 如果拦截 `npm.ps1`，可以临时执行：

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```

设置 AI Key：

```powershell
$env:OPENAI_API_KEY="你的 OpenAI API Key"
```

配置 Git 作者并登录 GitHub CLI：

```powershell
git config --global user.name "N1ght158"
git config --global user.email "你的 GitHub 邮箱"
gh auth login
```

## 基础 dry-run

只生成执行计划，不拉取仓库、不改代码：

```powershell
python .\src\csrf_autopilot.py run `
  --frontend https://github.com/acme/web `
  --backend https://github.com/acme/api `
  --provider github `
  --workspace .
```

## 仓库准备

执行远端访问检查、clone/fetch 和工作分支创建：

```powershell
python .\src\csrf_autopilot.py run `
  --frontend https://github.com/acme/web `
  --backend https://github.com/acme/api `
  --provider github `
  --base main `
  --workspace . `
  --execute-bootstrap
```

## A版：扫描、AI 决策和补丁草案

```powershell
python .\src\csrf_autopilot.py run `
  --frontend https://github.com/N1ght158/simple-web-target `
  --backend https://github.com/N1ght158/simple-api-target `
  --provider github `
  --base main `
  --workspace . `
  --run-id simple-draft-001 `
  --execute-bootstrap `
  --analyze-csrf `
  --ai-decide-fixes `
  --ai-generate-patch
```

该命令会生成扫描报告、AI 修复决策报告和 AI 补丁草案，但默认不会写入目标仓库。

## A版：复用草案并落地

```powershell
python .\src\csrf_autopilot.py run `
  --frontend https://github.com/N1ght158/simple-web-target `
  --backend https://github.com/N1ght158/simple-api-target `
  --provider github `
  --base main `
  --workspace . `
  --run-id simple-apply-001 `
  --ai-patch-draft-file .\reports\ai-patch-draft-simple-draft-001.json `
  --apply-ai-patch
```

复用草案适合先人工检查，再确认写入本地工作分支。

## A版：一条命令重新调用 AI 并创建 PR

```powershell
python .\src\csrf_autopilot.py run `
  --frontend https://github.com/N1ght158/simple-web-target `
  --backend https://github.com/N1ght158/simple-api-target `
  --provider github `
  --base main `
  --workspace . `
  --run-id simple-onepass-ai-001 `
  --execute-bootstrap `
  --analyze-csrf `
  --ai-decide-fixes `
  --ai-generate-patch `
  --apply-ai-patch `
  --create-pr
```

该命令会重新调用 AI，写入补丁，提交 commit，推送工作分支，并创建 GitHub PR。

## CI 验证

如需在落地后执行本地测试，可追加：

```powershell
--validate-ai-patch
```

也可以手动进入本地仓库运行：

```powershell
cd .\repos\simple-web-target
npm.cmd run test

cd ..\simple-api-target
npm.cmd run test
```

当前简单靶场的后端测试已通过；前端测试需要调整断言，因为 AI 可能把 CSRF header 封装到 `src/apiClient.js`，而不是直接写在 `src/App.jsx`。

## 输出结果

运行后会在 `reports/` 下生成：

- `run-plan-<run_id>.json/.md`
- `csrf-analysis-<run_id>.json/.md`
- `repair-decision-<run_id>.json/.md`
- `ai-patch-draft-<run_id>.json/.md`
- `ai-patch-apply-<run_id>.json/.md`
- `ci-gate-<run_id>.json/.md`
- `pr-automation-<run_id>.json/.md`
- `merge-execution-<run_id>.json/.md`

## 参数说明

- `--execute-bootstrap`：执行仓库准备。
- `--analyze-csrf`：生成 CSRF 风险识别报告。
- `--ai-decide-fixes`：调用 AI 生成修复决策。
- `--ai-generate-patch`：调用 AI 生成补丁草案。
- `--ai-patch-draft-file`：复用已有补丁草案。
- `--apply-ai-patch`：确认并写入 AI 补丁。
- `--validate-ai-patch`：执行本地 CI 闸门验证。
- `--create-pr`：提交、推送并创建 PR。
- `--auto-merge on-green`：仅在 CI 通过时允许进入自动合并评估。
