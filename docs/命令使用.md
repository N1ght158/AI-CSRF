# 命令使用

## Python 方式

```bash
python src/csrf_autopilot.py run \
  --frontend https://github.com/acme/web \
  --backend https://github.com/acme/api \
  --provider github \
  --base main \
  --auto-merge off \
  --workspace .
```

执行仓库准备（会做 clone/fetch 和建分支）：

```bash
python src/csrf_autopilot.py run \
  --frontend https://github.com/acme/web \
  --backend https://github.com/acme/api \
  --provider github \
  --base main \
  --workspace . \
  --branch-prefix ai/csrf-fix \
  --execute-bootstrap
```

A1/A2：启用 Codex 决策（默认低成本模型）

```bash
python src/csrf_autopilot.py run \
  --frontend https://github.com/acme/web \
  --backend https://github.com/acme/api \
  --workspace . \
  --analyze-csrf \
  --decide-fixes \
  --ai-decide-fixes \
  --ai-provider openai \
  --ai-model gpt-5.1-codex-mini
```

生成后端修复 MVP 改动：

```bash
python src/csrf_autopilot.py run \
  --frontend https://github.com/acme/web \
  --backend https://github.com/acme/api \
  --workspace . \
  --apply-backend-fix
```

生成前端修复 MVP 改动：

```bash
python src/csrf_autopilot.py run \
  --frontend https://github.com/acme/web \
  --backend https://github.com/acme/api \
  --workspace . \
  --apply-frontend-fix
```

执行 CI 闸门检查：

```bash
python src/csrf_autopilot.py run \
  --frontend https://github.com/acme/web \
  --backend https://github.com/acme/api \
  --workspace . \
  --run-ci-gate
```

自动提交 PR：

```bash
python src/csrf_autopilot.py run \
  --frontend https://github.com/acme/web \
  --backend https://github.com/acme/api \
  --workspace . \
  --create-pr
```

执行自动合并（需策略为 on-green）：

```bash
python src/csrf_autopilot.py run \
  --frontend https://github.com/acme/web \
  --backend https://github.com/acme/api \
  --workspace . \
  --auto-merge on-green \
  --run-ci-gate \
  --create-pr \
  --execute-merge
```

## PowerShell 方式

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\csrf-autopilot.ps1 `
  -Frontend https://github.com/acme/web `
  -Backend https://github.com/acme/api `
  -Provider github `
  -Base main `
  -AutoMerge off `
  -Workspace .
```

启用 AI 决策：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\csrf-autopilot.ps1 `
  -Frontend https://github.com/acme/web `
  -Backend https://github.com/acme/api `
  -Workspace . `
  -AnalyzeCsrf `
  -DecideFixes `
  -AiDecideFixes `
  -AiProvider openai `
  -AiModel gpt-5.1-codex-mini
```

## 输出结果

命令执行后会在 `reports/` 下生成基础计划文件：

- `run-plan-<run_id>.json`
- `run-plan-<run_id>.md`

如启用扫描与决策，还会生成：

- `csrf-analysis-<run_id>.json`
- `csrf-analysis-<run_id>.md`
- `repair-decision-<run_id>.json`
- `repair-decision-<run_id>.md`

如启用修复，还会生成：

- `backend-fix-<run_id>.json`
- `backend-fix-<run_id>.md`
- `frontend-fix-<run_id>.json`
- `frontend-fix-<run_id>.md`

如启用阶段6/7/8流程，还会生成：

- `ci-gate-<run_id>.json`
- `ci-gate-<run_id>.md`
- `pr-automation-<run_id>.json`
- `pr-automation-<run_id>.md`
- `merge-execution-<run_id>.json`
- `merge-execution-<run_id>.md`

## 补充说明

- 默认是 dry-run，不会访问远端仓库。
- 追加 `--execute-bootstrap` 后，会执行远端访问检查、clone/fetch 与工作分支创建。
- A1/A2 里若启用了 `--ai-decide-fixes`，会调用 AI 生成修复决策；若 AI 调用失败，会降级为规则决策并在报告中标注。
- 追加 `--apply-backend-fix` 后，才会尝试在本地后端仓库生成修复改动；当前 MVP 仅支持 Express CommonJS。
- 追加 `--apply-frontend-fix` 后，才会尝试在本地前端仓库生成修复改动；当前 MVP 仅支持 Axios 请求封装。
- 追加 `--run-ci-gate` 后，会在本地仓库执行检测到的 lint/test 命令，并作为合并闸门。
- 追加 `--create-pr` 后，会尝试提交改动、推送分支并创建 PR；如缺少平台 CLI 工具，将输出手动命令。
- 只有在 `--auto-merge on-green` 且 CI 闸门通过时才允许合并；是否真正执行合并由 `--execute-merge` 控制。
